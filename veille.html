Méthodologie de veille

  • Sources : CERT-FR (vulnérabilités, alertes), Zataz (actualité francophone), The Hacker News (menaces internationales).
  • Collecte : flux RSS, affichés ici en direct et envoyés chaque matin par email via mon bot Python / GitHub Actions.
  • Tri : filtrage par mots-clés pour ne garder que les alertes critiques.
  • Objectif : repérer les vulnérabilités qui concernent les outils que j'administre (Windows Server, Linux, pfSense, Wazuh…) et appliquer les correctifs.
